# Thiranex_Week_4
\## 📌 Project Overview This repository contains the completed capstone project for \*\*Task 4 (Real-world Data Project)\*\* of the Thiranex Data Science Internship. The objective of this project is to execute an end-to-end retail analytics workflow on e-commerce transaction data to evaluate sales performance, identify top-revenue product categories, analyze seasonality trends, and segment customers based on spending tiers. --- ## 🛠️ Analytics Pipeline Workflow 1\. \*\*Data Preprocessing &amp; Feature Engineering\*\*: - Calculated total sales revenue per transaction (\`Total\_Sales = Quantity \* UnitPrice\`). - Parsed datetime attributes to extract monthly and day-of-week seasonality metrics. - Filtered out invalid transactions and non-positive prices. 2\. \*\*Sales Trend &amp; Seasonality Analysis\*\*: - Aggregated monthly sales revenue across the full project timeline. - Evaluated revenue distribution across core product categories (\*Electronics, Home &amp; Kitchen, Apparel, Books, Beauty &amp; Health\*). 3\. \*\*Customer Spending Segmentation\*\*: - Aggregated metrics per customer: \`Total\_Spent\`, \`Order\_Count\`, and \`Avg\_Order\_Value\`. - Segmented customers into four spending tiers (\*\*Low Spender\*\*, \*\*Mid Spender\*\*, \*\*High Spender\*\*, \*\*VIP Spender\*\*) using quartile metrics (\`qcut\`). 4\. \*\*Actionable Business Recommendations\*\*: - Formulated data-driven strategies for inventory stock management, VIP customer retention programs, and targeted seasonal promotions. --- ## 📊 Visualizations Generated \* \*\*\`monthly\_sales\_trend.png\`\*\*: Time-series line chart depicting monthly sales revenue trends over time. \* \*\*\`category\_revenue\_share.png\`\*\*: Bar chart ranking product categories by total sales volume. \* \*\*\`customer\_segmentation.png\`\*\*: Distribution plot showing customer counts across spending tiers. --- ## 📁 Repository Structure \`\`\`text Thiranex\_Week\_4/ │ ├── [suspicious link removed] # End-to-End Retail Analytics Python Pipeline ├── online\_retail.csv # E-commerce Transaction Dataset └── [suspicious link removed] # Project Documentation
